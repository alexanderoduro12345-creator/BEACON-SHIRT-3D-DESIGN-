# Beacon

A premium custom apparel concept app inspired by the blankbuilder style, rebranded as Beacon and updated to work online and offline.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```

## Offline support

This app uses a service worker and browser local storage so the core experience remains available even when you're offline after the initial load.
